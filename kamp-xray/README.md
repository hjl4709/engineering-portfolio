# 분말 유크림 X-ray 이물 검출

제6회 K-인공지능 제조데이터 분석 경진대회에서 분말 유크림 완제품의 X-ray 영상에 이물 의심 위치를 표시하는 모델을 개선했다. 작은 이물은 모델이 위치를 찾아도 예측 박스가 너무 크면 미탐으로 집계됐다. 팀장으로 모델 검토와 튜닝을 총괄하고 결과를 발표했다.

## 최종 결과

촬영일 기준으로 학습 350장, 검증 57장, 시험 90장을 나눴다. 아래 수치는 동일 시험 영상 90장에 표시된 정답 이물 194개를 기준으로 비교한 결과다.

| 모델 | 판정 기준 | 정확히 찾은 이물 | 놓친 이물 | 잘못 낸 경보 | F1 |
| --- | ---: | ---: | ---: | ---: | ---: |
| YOLO11s | 0.67 | 183 | 11 | 7 | 95.31% |
| YOLO11s + 박스 크기 보정 CNN | 0.67 | 185 | 9 | 5 | 96.35% |
| YOLO11s + 박스 크기 보정 CNN | 0.63 | 187 | 7 | 6 | 96.64% |

같은 판정 기준에서 CNN으로 예측 박스의 폭과 높이를 조정하자 미탐과 오탐이 각각 2개 줄었다. 이후 검증 영상에서 선택한 기준 0.63을 적용해 이물 2개를 더 찾았고 오탐은 1개 늘었다. 최종 보고서의 그림 2-2와 표 2-5에 해당하는 비교다.

## 공개 코드 실행

[기준 모델 실험 노트북](baseline.ipynb)은 CNN 보정기를 추가하기 전의 실험 코드다. 장비의 색 표시 제거, 촬영일을 고려한 자료 분할, YOLO 검출기 후보 학습, 미탐·오탐 평가까지 담고 있다. 위 표는 후속 CNN 실험을 포함한 최종 보고서의 결과다.

1. 원본 KAMP X-ray 검사장비 데이터셋의 압축을 풀고 `4. X-ray 검사장비 AI 데이터셋/` 폴더를 이 노트북 옆에 둔다. 장비별 BMP와 `라벨링 6종 세트/labels/` 아래 TXT의 원래 구조를 유지한다.
2. GPU와 호환되는 PyTorch를 준비하고 아래 명령으로 라이브러리를 설치한다.
3. 이 폴더에서 Jupyter를 실행해 `baseline.ipynb`를 연다. 기본 `smoke` 모드는 소량 자료로 실행 경로를 점검한다. 전체 기준 모델 비교는 `XRAY_RUN_MODE=full`로 실행한다. 학습 가중치는 첫 실행 때 내려받으며 결과는 `submission_work/`에 저장된다.

```shell
python -m pip install -r requirements.txt
python -m notebook baseline.ipynb
```
