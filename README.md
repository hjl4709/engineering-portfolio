# 이현중 | 제조·반도체 프로젝트

기계시스템공학과 반도체를 전공하며 진행한 장비 설계 과제와 제조 데이터 분석 프로젝트를 모았다. 각 프로젝트에서 맡은 일과 팀의 결과를 설계 이미지, 실험 기록, 노트북으로 정리했다.

| 프로젝트 | 맡은 일 | 결과 |
| --- | --- | --- |
| [모형 웨이퍼 이송 로봇](wafer-transfer/) | Fusion 360 모델링·렌더링, 받침 구조 해석, 보고서 작성 | 받침을 3 mm로 선정. 팀 시제품의 한 사이클이 100초에서 약 40초로 단축 |
| [식품 X-ray 이물 검출](kamp-xray/) | 팀장, 모델 검토·튜닝 총괄, 최종 발표 | 시험 영상 90장에서 이물 194개 중 187개 검출. 기준 모델보다 4개 추가 검출 |
| [실리콘 잉곳의 기포 제어](ingot-bubbles/) | 내부 진동판 제안, 최종 발표 | 초기 아이디어 4개를 검토해 내부 진동판과 외벽 진동자 2개 설계안을 발표 |
| [폐기물 이미지 12종 분류](https://github.com/hjl4709/17-team_project4) | 팀장, 중복 이미지 판별과 라벨 검수 | 같은 조건에서 라벨 정정 후 의류를 신발로 분류한 오류가 8건에서 3건으로 감소 |
